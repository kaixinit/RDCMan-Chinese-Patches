# 依赖说明

本源码包不包含依赖 DLL，也不会下载 RDCMan。

唯一代码依赖：**Mono.Cecil 0.11.6**。

- [NuGet 固定版本页面](https://www.nuget.org/packages/Mono.Cecil/0.11.6)
- [项目与该版本许可](https://github.com/jbevain/cecil/blob/0.11.6/LICENSE.txt)
- 包中 `Mono.Cecil.nuspec` 的许可标识：MIT；`requireLicenseAcceptance` 为 false。
- Windows PowerShell 5.1 使用包内 `lib/net40/Mono.Cecil.dll`。
- PowerShell 7 使用包内 `lib/netstandard2.0/Mono.Cecil.dll`。

`Prepare-Dependency.ps1` 只从 `patch.json` 中固定的 NuGet HTTPS 地址下载，再校验整个包和目标 DLL；离线包走相同检查。缓存默认位于 `.local/dependencies`，已被 Git 忽略。

运行检查使用系统 .NET Framework 4.x 编译器，将项目自编 `RuntimeChecks.cs` 编译到临时目录，执行后删除检查 EXE。它不含微软应用的源码，不启动 RDCMan，也不读取个人连接设置。
