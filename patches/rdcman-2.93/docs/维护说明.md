# 维护说明

## 文件分工

- `patch.json`：唯一支持的原版哈希、版本、条目数量、产品标识和依赖校验值。
- `patches/translations.json`：精确方法、指令索引、预期原文和中文，不是全局查找替换。
- `scripts/Apply-Strings.ps1`：校验每个位置后替换文字，隔离学习版设置目录，复核所有原方法。
- `scripts/Apply-Ui.ps1`：仅在有结构校验的界面方法中补充显示映射和尺寸调整；四个纯显示辅助方法不更改持久化值。
- `scripts/Verify-Pe.ps1`：比较 Windows 原生资源及 PE 签名目录。
- `tests/RuntimeChecks.cs`：28 项无界面运行检查，包括未知用户名称、内部配置键、凭据显示、移除描述、异常 XML，以及有效/无效导入范围与中文错误。
- `tests/Test-Workflow.ps1`：完整构建、复检、恢复与错误输入保护测试；测试输出必须放在新目录。

## 修改翻译

1. 先保存当前项目副本。只修改匹配条目的 `Chinese`，不要随意改 `Method`、`Index` 或 `English`。
2. 保留 `{0}` 等格式占位符以及有意保留的快捷键。XML 节点、内部配置名和用户自定义名称不属于显示译文。
3. 若新增条目，应查明它只用于显示；不得按相同英文在所有位置批量替换。
4. 同步 `patch.json` 的数量及 `docs/中英对照.tsv`，检查实际界面，尤其是错误状态和不同长度的名称。
5. 运行 `Update-SourceManifest.ps1` 更新源文件清单，然后重新构建和测试。哈希清单只检测意外变化，不能证明来源可信或解决版权授权。

PowerShell 文件使用 UTF-8 BOM 以兼容 Windows PowerShell 5.1。`.gitattributes` 禁用自动换行转换以保留清单对应的精确字节；编辑器若改变换行或编码，也需要重新生成清单。

### 启动提示的维护位置

0.1.1 的启动提示修复位于同一份 `patches/translations.json`：条目 330 是共用警告框标题，734 是启动说明，735 是继续启动及保存风险说明，1072 是未知 XML 节点的格式文本。共用标题同时用于其他警告，修改时应使用“RDCMan 提示”这类通用表述。

`Apply-RdcManPatch.ps1` 会读取并应用这些条目；`scripts/Apply-Strings.ps1` 逐一校验对应方法、指令索引和原文，再验证新文字。保留条目 1072 中的 `{0}`，以显示原始 XML 路径；不要改写原始配置或用无条件忽略错误替代文字修复。`docs/中英对照.tsv` 应保持同步。

```powershell
.\Update-SourceManifest.ps1
$cecil = .\Prepare-Dependency.ps1 -Download
.\tests\Test-Workflow.ps1 -SourcePath 'D:\Tools\RDCMan293\RDCMan.exe' -CecilPath $cecil -WorkDirectory 'D:\PatchTests\Run-001'
```

不要移除原版哈希检查以兼容新版本。不同版本需要单独建项目、重新定位和验收，不应套用这些指令索引。

## 输出与保护范围

只有全部检查通过，临时目录中的产品目录才会原子移动到指定的新输出目录。失败材料留在临时目录以便排查。输入原版、已有输出目录和用户设置不会被修改。

恢复只针对输出目录，检查备份和目标哈希后用原版替换汉化副本，并保留汉化备份。不要手工编辑 `patch-report.json` 来覆盖未知程序。

`Test-RdcManPatch.ps1` 对构建时校验过的副本做哈希、资源与运行复检；它不会重新构建副本。恢复后会转为检查原版字节状态。

本地输出的哈希以该次报告为准；编写器元数据或目标框架差异可能导致与早先手工构建的副本哈希不同。不能据此省略行为和资源检查。

## 准备源码包

不要直接压缩整个工作目录。`Package-Source.ps1` 只打包 `source-manifest.json` 中的明确清单，并检查二进制魔数、私人配置扩展名与用户绝对路径。后续添加源文件时，还需同步 `Update-SourceManifest.ps1` 的允许清单。

不得把本地生成的程序、原版备份、依赖缓存、`.rdg`、`.settings`、调试日志、测试工作目录或含真实主机/账号的截图加入分享包。
