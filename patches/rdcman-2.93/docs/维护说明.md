# 模块维护说明

## 文件职责

- `patch.json`：受支持原版、补丁版本和固定依赖。
- `patches/translations.json`：原文、译文及精确定位信息。
- `scripts/Apply-Strings.ps1`：固定文字替换与原始内容校验。
- `scripts/Apply-Ui.ps1`：动态显示及限定界面的排版处理。
- `tests/Test-Workflow.ps1`：构建、复检、恢复和错误输入保护流程。
- `scripts/Verify-Pe.ps1` 和 `tests/RuntimeChecks.cs`：资源、程序结构及无界面运行检查。

## 修改原则

只调整用于显示的文字。修改译文时保留格式占位符、原始匹配信息与必要快捷键；新增条目同步数量和 `docs/中英对照.tsv`。

XML 节点、枚举、配置键、凭据内部标识和用户自定义内容不作为译文替换。不要移除原版或依赖的哈希检查来兼容未知版本。

动态文字与布局修改应保持限定方法校验、原有缩放机制和序列化行为。关于窗口保留原软件版权及作者信息，汉化维护署名单独显示；不改变产品属性和配置目录。

## 验证

修改后先在仓库根目录更新清单，再使用对应原版在新目录构建和复检。涉及界面或错误处理的变更，应人工验证相关状态。

PowerShell 文件使用 UTF-8 BOM，Git 换行处理遵循 `.gitattributes`。源码校验、完整流程测试和打包步骤见[维护指南](../../../docs/MAINTENANCE.md)。
