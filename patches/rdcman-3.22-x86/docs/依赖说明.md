# 依赖说明

以下命令在本模块目录执行。依赖精确版本及 SHA256 由 `patch.json` 固定，源码包不附带依赖二进制。

## Mono.Cecil

使用 [Mono.Cecil 0.11.6](https://www.nuget.org/packages/Mono.Cecil/0.11.6)。Windows PowerShell 5.1 读取 net40 DLL，PowerShell 7 读取 netstandard2.0 DLL。

```powershell
$cecil = .\Prepare-Dependency.ps1 -Download
```

或使用自行准备的固定离线包：

```powershell
$package = Read-Host 'mono.cecil.0.11.6.nupkg 的完整路径'
$cecil = .\Prepare-Dependency.ps1 -PackagePath $package
```

包和目标 DLL 均须通过哈希检查。默认缓存位于 `.local`，不得作为发布附件。

## Python

构建和复检需要 Python 3.9+，仅使用标准库。未加入 PATH 时，可通过 `-PythonPath` 指定解释器；脚本不安装 Python。

## x86 原生运行库

默认 RDCore 需要 `patch.json` 指定的微软 x86 VC++ 运行库。准备工具校验包、架构和微软签名，仅提取文件，不执行安装器。

```powershell
$runtime = .\Prepare-Runtime.ps1 -Download
```

离线方式：

```powershell
$package = Read-Host '指定版本 VC_redist.x86.exe 的完整路径'
$runtime = .\Prepare-Runtime.ps1 -PackagePath $package
```

同名的其他版本安装包可能不匹配。运行库仅参与本地成品构建，不写入系统目录，也不进入源码 ZIP。

依赖的版权与来源见[第三方说明](../../../THIRD_PARTY_NOTICES.md)。
