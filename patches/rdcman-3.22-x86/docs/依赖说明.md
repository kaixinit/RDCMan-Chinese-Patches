# 依赖说明

## RDCore 所需的微软 x86 VC++ 运行库

0.1.2 固定使用微软 14.51.36247.0 x86 包，地址和 SHA256 见 `patch.json` 的 `nativeRuntime`。官方背景说明：[Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。本包通过固定微软下载地址获取同一版本，不使用“最新版本”作为不校验的浮动依赖。

```powershell
$runtime = .\Prepare-Runtime.ps1 -Download
# 或者使用手动下载的精确版本
$runtime = .\Prepare-Runtime.ps1 -PackagePath 'D:\Packages\VC_redist.x86.exe'
```

脚本验证包 SHA256 和微软签名，使用 Python 与 Windows 自带的 expand.exe 提取柜文件，不启动安装器、不接受安装协议、不注册系统组件。7 项 DLL 各自验证哈希、x86 PE32 架构和签名。默认缓存在 `.local/native-runtime`；可传入 `-CacheDirectory` 指定其他路径。

构建将它们作为原生文件嵌入 EXE，与 RDCoreSdk.dll 一起提取；不会复制到 Windows 系统目录。源码 ZIP 不包含微软安装包或运行库 DLL，成品中的微软组件适用其原有许可。

## Python

需要 Python 3.9 或更新版本。`scripts/Bundle.py` 只使用 `argparse`、`array`、`hashlib`、`json`、`pathlib`、`struct`、`sys`、`zlib` 等标准库，不需要安装 pip 包。

脚本查找 `python.exe`，其次查找 `py.exe -3`，并验证版本；可用 `-PythonPath` 指定完整路径。脚本不安装 Python，也不会调用 Microsoft Store 安装占位别名。构建和复检需要 Python；预览及恢复不需要。

## Mono.Cecil

固定版本为 0.11.6，官方 NuGet 包地址：

https://api.nuget.org/v3-flatcontainer/mono.cecil/0.11.6/mono.cecil.0.11.6.nupkg

| 文件 | SHA256 |
|---|---|
| 原始 nupkg | D2A23832AAA948BA9A01ACC42B5726E34C5F995958F1B30D45C0E7C70B3A72D5 |
| net40/Mono.Cecil.dll | C41BDB9FFD3C5F6E17D2382C1012D73703E035E3F1100245FDD4E08C8DC6EB5B |
| netstandard2.0/Mono.Cecil.dll | 831DCA77470D85CB6FFBEA3072DAA7A3DF5B7C9FCFD9C3F43674A9BE99D4BFCF |

Windows PowerShell 5.1 使用 net40；PowerShell 7 使用 netstandard2.0。依赖默认缓存到补丁目录的 `.local/dependencies`，不应随源码包分享。

为保证旧版 PowerShell 能解析 3.22 的运行库类型，构建时会从固定哈希的原版包提取根目录托管程序集作为临时元数据引用。它们只由 Mono.Cecil 读取，不会执行；不需要为此安装另一套 .NET 运行库，引用文件也不会被放入源码包。

在线准备需显式传入下载参数：

```powershell
.\Prepare-Dependency.ps1 -Download
```

离线方式：

```powershell
.\Prepare-Dependency.ps1 -PackagePath 'D:\Packages\mono.cecil.0.11.6.nupkg'
```

准备步骤验证包和 DLL 后才写入缓存。已有缓存不匹配时拒绝覆盖。源码包不附带第三方 DLL；Mono.Cecil 的许可和声明以官方包为准。脚本不下载 RDCMan。
