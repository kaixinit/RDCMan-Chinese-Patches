# 维护说明

## 文件分工

- `patch.json`：目标版本、原版 EXE 与包内程序集哈希、翻译数量和固定依赖。
- `patches/translations.json`：精确方法、指令索引、预期英文和中文。
- `scripts/Apply-Strings.ps1`：校验并替换固定文字，设置独立产品名称，复核所有原方法、资源和依赖。
- `scripts/Apply-Ui.ps1`：仅对明确列出的显示方法做动态文字及布局调整，保留持久化值和用户名称。
- `scripts/Bundle.py`：自行编写的单文件包提取、重打包及字节校验工具，使用 Python 标准库。
- `tests/Test-Workflow.ps1`：构建、复检、恢复与错误输入保护流程；只在新的测试目录操作，不启动应用。

## 修改与验证

修改翻译时同步 `docs/中英对照.tsv`。新增条目需先确认原文、方法和指令位置；数量变化时同步 `patch.json`。PowerShell 文件使用 UTF-8 BOM；`.gitattributes` 禁用自动换行转换，保持源清单对应的字节。

```powershell
.\Update-SourceManifest.ps1
$cecil = .\Prepare-Dependency.ps1 -PackagePath 'D:\Packages\mono.cecil.0.11.6.nupkg'
.\tests\Test-Workflow.ps1 -SourcePath 'D:\Tools\RDCMan322\RDCMan.exe' -CecilPath $cecil -WorkDirectory 'D:\PatchTests\Run-001'
```

测试支持 `-PythonPath`。构建脚本先校验源包和所有翻译，再在独立暂存目录生成；仅成功后移动生成目录。清理只针对本次生成并校验过边界的暂存目录。失败材料留在输出父目录，不能一起分享。

## 源码打包

```powershell
.\Package-Source.ps1 -DestinationZip 'D:\Exports\RDCMan-3.22-zh-patch-source.zip'
```

打包使用明确允许清单，并拒绝程序、依赖二进制、用户绝对路径和连接配置。新增源文件需同步 `Update-SourceManifest.ps1` 的清单。不要直接压缩整个工作目录，尤其不要包含 `.local`、测试目录、原版、生成的 EXE/DLL、账户配置或截图。

源清单检测意外变化，不是数字签名、来源证明或版权授权。不同构建环境下的成品哈希应以对应报告为准，不可省略方法、资源和单文件包校验。
